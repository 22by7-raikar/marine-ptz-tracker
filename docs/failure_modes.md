# Failure modes and operational response

The entries below describe implemented software responses where applicable and
identify the remaining physical evidence. The Arduino watchdog is a
communication fallback, **not** an emergency stop.

| Failure | Trigger and detection | Software response | Firmware response | Operator response | Residual risk | Evidence status |
| --- | --- | --- | --- | --- | --- | --- |
| No target | Selector has no matching detection. | Apply configured lost-target policy through bounded controller. | Last valid command/watchdog policy remains applicable. | Observe expected hold/neutral behavior; stop if unexpected. | Existing physical position may remain until a new command/timeout. | PASS — software validated; PENDING — end-to-end |
| False detection | Detector labels non-target as target. | Selector filters configured normalized classes; controller remains bounded. | Limits only angle, not semantic correctness. | Use representative replay and adjust reviewed policy only after evidence. | Incorrect but bounded motion. | PENDING — real media |
| Multiple boats | Several target-class detections. | Deterministic confidence/area/center/coordinate selection. | No selection awareness. | Record ambiguity cases and confirm desired policy. | Target switching can be visually undesirable. | PASS — software validated; PENDING — real media |
| Camera open failure | Capture cannot be opened. | Fail before serial open/enable; report failure and clean up. | Remains detached unless separately enabled. | Check camera identity/cable; do not arm hardware. | No perception result. | PASS — software validated; PENDING — camera |
| Camera disconnect/read failure | OpenCV live read fails. | Raise failure, stop commands, bounded cleanup/disable attempt. | Watchdog can detach if communication stops. | Remove external power if motion/state is uncertain; diagnose camera. | A command already sent may persist until timeout. | PASS — software validated; PENDING — camera/end-to-end |
| Malformed frame | Unsupported dimensions/channels or invalid frame data. | Reject at capture boundary and clean up. | No new command expected. | Preserve error/log, inspect source format. | No physical proof for delivered camera codecs. | PASS — software validated; PENDING — camera |
| Detector/model failure | Model load/inference/device error. | Fail before enable when startup; otherwise stop and clean up. | Watchdog fallback after host stops communicating. | Keep/restore simulated actuation while diagnosing. | Model failure cannot itself disable external power. | PASS — software validated; PENDING — real media |
| CUDA unavailable | Requested CUDA cannot be resolved. | Actionable device error; no automatic package/environment change. | No command if startup fails. | Verify on host; sandbox-only absence is not host evidence. | CPU fallback must be explicitly selected/evaluated. | PASS — software validated; PENDING — camera performance |
| Serial port absent | Explicit path cannot open. | Fail closed; no auto-discovery and no enable. | Unchanged/detached after reset as applicable. | Verify `/dev/serial/by-id/...` identity; do not guess a port. | USB identity can change. | PASS — software validated; PENDING — serial |
| Uno auto-reset | Port open resets board. | Bounded boot grace and repeated correlated `HELLO`; requires `DISABLE` ACK. | Startup `READY 0`; remains detached until `ENABLE`. | Capture handshake transcript with servos disconnected first. | Reset timing differs by board/USB stack. | PASS — software validated; PENDING — serial |
| HELLO timeout | No correlated `READY` before deadline. | Close session without `ENABLE`; report failure. | May remain detached or reset. | Check cable/board/baud only with no-servo setup. | Physical serial timing unmeasured. | PASS — software validated; PENDING — serial |
| Lost ENABLE ACK | Enable may have applied but acknowledgement is lost. | Fault/uncertainty policy blocks subsequent motion and runs bounded cleanup. | Enabled state can persist until disable/watchdog. | Remove external servo power if state is uncertain; inspect transcript. | Software cannot guarantee a lost disable reaches board. | PASS — software validated; PENDING — serial/end-to-end |
| Lost SET ACK | Set may have physically applied without host confirmation. | Preserve confirmed coordinates, mark uncertainty, block further apply until recovery. | Accepted duplicate semantics/watchdog policy apply. | Treat position as uncertain; remove external power if unsafe. | Physical position may differ from host-confirmed value. | PASS — software validated; PENDING — serial/end-to-end |
| Malformed firmware response | ACK/STATUS violates protocol semantics. | Central fault state blocks `apply`; cleanup closes transport. | Not inferable from malformed data. | Stop operation and recover only with a new successful handshake. | Board may still be enabled until watchdog/physical power removal. | PASS — software validated; PENDING — serial |
| Watchdog expiry | Accepted motion traffic stops beyond firmware deadline. | Host detects fault where possible; no new motion after cancellation/fault. | Detaches servos once and enters expired state. | Conduct controlled no-load test and record timing. | Not safety-rated; power/mechanics can still be hazardous. | PASS — software/model validated; PENDING — serial/servo |
| SIGINT/SIGTERM | Process receives termination request. | Record request, stop new motion at safety boundaries, bounded cleanup; statuses 130/143. | Receives bounded `DISABLE` only if delivery succeeds; otherwise watchdog fallback. | Keep external-power removal available. | Kill/power/USB failure can interrupt cleanup. | PASS — software validated; PENDING — end-to-end |
| External servo power loss | Servo rail is removed or sags. | Host may not observe it immediately. | Commands can continue logically but servos cannot move. | Stop, meter-check supply/polarity/capacity before restoring power. | Position/host state diverge; reset may cause movement considerations. | PENDING — servo |
| USB disconnect | Camera or Uno cable disconnects. | Source/transport failure stops loop and runs cleanup where possible. | Uno watchdog may detach after host traffic ends. | Remove servo power if state is uncertain; reconnect only after inspection. | Disconnect can prevent explicit disable delivery. | PASS — software validated; PENDING — end-to-end |
| Common-ground loss | Servo signal loses shared reference. | Software cannot directly detect it. | PWM interpretation may be unreliable. | Remove external power; restore/verify ground before retry. | Unpredictable servo behavior. | PENDING — servo |
| Reversed supply polarity | External rail is wired incorrectly. | No reliable software detection. | No reliable protection assumed. | Do not power; meter-check before every wiring change. | Equipment damage/fire risk. | PENDING — safety inspection |
| Mechanical binding | Linkage reaches obstruction/end stop. | Controller limits logical angles but cannot sense torque/binding. | Enforces configured angle limits only. | Remove power; adjust mechanical limits/calibration. | Damage, current spikes, or heat. | PENDING — servo |
| Servo saturation | Command reaches configured lower/upper limit. | Controller/actuator clamp and replay records saturation counts. | Firmware rejects out-of-range commands. | Investigate cause; do not widen limits without clearance evidence. | Limit can conceal poor tracking/calibration. | PASS — software validated; PENDING — servo |
| Excessive oscillation | Repeated corrections or unstable target selection. | Gain/deadband/max-step/update-rate are configurable and bounded. | Executes valid commands only. | Stop physical test, collect telemetry, tune from evidence. | Bounded but repeated motion can stress mechanics/power. | PASS — software validated; PENDING — end-to-end |
| Toy boat not detected | Model has no qualifying boat detection. | Lost-target policy; replay exposes selected-target ratio. | No semantic fallback. | Capture representative media; review model/class/confidence and lighting. | No tracking or stale pose behavior depending on policy. | PENDING — real media |
